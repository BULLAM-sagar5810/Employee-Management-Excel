# Employee Management System – Excel-Based Project

## Overview

The Employee Management System is an Excel-based project designed to manage and analyze employee information, attendance records, and salary details within an organization. The project demonstrates how spreadsheet tools can be used to organize workforce data, automate calculations, and generate meaningful insights for HR and payroll management.

This project consists of three major modules:

### 1. Employee Details Management

Maintains employee master data including:

* Employee ID
* Employee Name
* Department
* Designation
* Location
* Date of Joining
* Basic Salary

This module serves as the central repository for employee information and helps maintain accurate employee records.

### 2. Employee Attendance Management

Tracks employee attendance and performance metrics including:

* Working Days
* Present Days
* Attendance Percentage
* Performance Percentage
* Incentive Calculations
* Net Salary Impact

The attendance module helps organizations monitor employee productivity and evaluate attendance-based incentives.

### 3. Employee Salary Management

Handles payroll processing and salary calculations including:

* Basic Salary
* House Rent Allowance (HRA)
* Dearness Allowance (DA)
* Other Allowances
* Provident Fund (PF)
* Tax Deductions
* Net Salary Calculation

This module automates payroll calculations and provides transparency in employee compensation management.
